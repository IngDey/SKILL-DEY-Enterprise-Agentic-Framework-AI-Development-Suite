**SKILL DEY** es un marco de trabajo (*framework*) agentico de nivel empresarial diseñado para potenciar el desarrollo de software asistido por Inteligencia Artificial. 

Combina una **arquitectura multi-agente especializada**, **memoria técnica persistente**, integración nativa con **MCP (Model Context Protocol)** y un conjunto de herramientas para auditoría, diagnóstico y seguridad.

---

## 🔥 ¿Por qué usar SKILL DEY?

* 🤖 **Arquitectura Multi-Agente:**
  * **Explorador:** Rastreo inteligente y mapeo de contexto en repositorios complejos.
  * **Revisor:** Auditoría de código en tiempo real y cumplimiento de estándares de calidad.
  * **Visión:** Inspección y conversión de maquetas / UI directamente a código estructurado.
* 🧠 **Memoria Técnica Persistente:** Mantiene el contexto del proyecto a lo largo del tiempo mediante registros estructurados (`BITACORA`, `DECISIONES`, `LECCIONES`).
* 🔌 **Soporte Nativo MCP:** Interoperable con **Cursor**, **VS Code** (Continue/OpenCode) y **Claude Desktop**.
* 🛡️ **Guardián de Ejecución:** Prevención de comandos destructivos y auditoría de seguridad local.
