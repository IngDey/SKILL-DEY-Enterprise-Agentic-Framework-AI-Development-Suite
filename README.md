🚀 SKILL DEY: Enterprise Agentic Framework & AI Development Suite

License: MIT Node.js Version MCP Ready Multi-Agent

SKILL DEY es un marco de trabajo (framework) agéntico de nivel profesional diseñado para potenciar el desarrollo de software asistido por Inteligencia Artificial.

Combina una arquitectura multi-agente especializada, memoria técnica persistente, integración nativa con MCP (Model Context Protocol) y un conjunto de herramientas para auditoría, diagnóstico y seguridad.

🔥 ¿Por qué usar SKILL DEY?
🤖 Arquitectura multi-agente: Explorador, Revisor y Visión trabajando cada uno en lo suyo.
🧠 Memoria técnica persistente: el contexto del proyecto se conserva a lo largo del tiempo.
🔌 Soporte nativo MCP: interoperable con Cursor, VS Code (Continue/OpenCode) y Claude Desktop.
🛡️ Guardián de ejecución: prevención de comandos destructivos y auditoría de seguridad local.
🤖 Arquitectura multi-agente
Agente	Qué hace	Cuándo usarlo
Explorador	Rastreo inteligente y mapeo de contexto en repositorios complejos.	Al entrar a un proyecto nuevo o muy grande.
Revisor	Auditoría de código en tiempo real y cumplimiento de estándares de calidad.	Antes de un commit o de abrir un pull request.
Visión	Inspección y conversión de maquetas / UI directamente a código estructurado.	Cuando tienes un diseño y necesitas el código.
🧠 Memoria técnica persistente

La suite guarda el conocimiento del proyecto en registros estructurados para que no se pierda entre sesiones:

Registro	Contenido
BITACORA	Qué se hizo y cuándo.
DECISIONES	Decisiones técnicas tomadas y por qué.
LECCIONES	Errores y aprendizajes para no repetirlos.
⚡ Instalación rápida

Requisitos: Node.js 18 o superior y Git.

1. Clonar el repositorio
bash
git clone https://github.com/IngDey/SKILL-DEY-Enterprise-Agentic-Framework-AI-Development-Suite.git
cd SKILL-DEY-Enterprise-Agentic-Framework-AI-Development-Suite

¿No usas Git? Descarga el .zip desde la sección Releases y descomprímelo.

2. Ejecutar el instalador
Windows: doble clic en INSTALAR.bat
macOS: doble clic en INSTALAR.command
